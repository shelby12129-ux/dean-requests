# Эскизный прототип интерфейса

## Состав экранов

| № | Экран | Задача |
|---|-------|--------|
| 1 | Форма подачи заявки | Студент создаёт заявку |
| 2 | Список заявок | Диспетчер видит все заявки |
| 3 | Личный кабинет студента | Студент следит за статусом |

## Экран 1. Форма подачи заявки

**Для кого:** студент.
**Связан с историей:** «Как студент, я хочу подать заявку».

**Структура:**
- Шапка: «Новая заявка».
- Поле «Тип заявки» (выпадающий список).
- Поле «Описание» (текстовое, обязательно).
- Поле «Файл» (прикрепить, необязательно).
- Кнопки: «Отправить», «Отмена».

## Экран 2. Список заявок

**Для кого:** сотрудник деканата.
**Связан с историей:** «Как диспетчер, я хочу видеть список заявок».

**Структура:**
- Шапка: поиск + фильтры.
- Таблица: № | Дата | Студент | Статус | Действие.
- Постраничная навигация.

## Экран 3. Личный кабинет студента

**Для кого:** студент.
**Связан с историей:** «Как студент, я хочу видеть статус заявки».

**Структура:**
- Шапка: «Мои заявки».
- Таблица: № | Дата | Тип | Статус.
- Кнопка «Подать новую заявку».

## Трассировка

| Экран | История |
|-------|---------|
| Форма подачи | История 1 |
| Список заявок | История 3 |
| Личный кабинет | История 2 |
