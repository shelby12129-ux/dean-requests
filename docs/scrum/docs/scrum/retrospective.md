# Ретроспектива Scrum-симуляции

Дата: 08.10.2026
Участники: Ишанов Афроз, Рахматуллозода Чехрон.
Формат: «Что хорошо — что улучшить — одно действие».

## Что хорошо

1. Покер планирования выявил разные оценки по истории «Запись на мероприятие».
   Расхождение 2 vs 8 поинтов показало, что команда понимала задачу по-разному.
   Обсуждение устранило непонимание до начала работы.
2. Два спринта прошли без срыва цели спринта.
3. Ежедневные скрамы выявили один блокер (нужен доступ к репозиторию) — устранён в тот же день.

## Что улучшить

1. Оценки историй по-прежнему «на глаз», без опоры на прошлый опыт.
2. Одна история перенесена из спринта 2 в следующий — команда переоценила скорость.
3. Протокол обзора спринта был коротким — не зафиксировали все замечания владельца продукта.

## Одно конкретное действие

**Действие:** перед каждым следующим спринтом сверять оценку истории
со средней velocity за прошлые спринты.

**Ответственный:** Рахматуллозода Чехрон.
**Срок:** к началу первого «настоящего» спринта проекта.

## Итог

Ретроспектива проведена по формату «Что хорошо — что улучшить — одно действие».
Одно действие выбрано и назначено. Следующая ретроспектива — в конце первого спринта проекта.
