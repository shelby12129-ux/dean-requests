# Цель первого спринта проекта

Дата планирования: 08.10.2026
Длительность спринта: 2 недели (08.10 – 22.10.2026)
Команда: Ишанов Афроз, Рахматуллозода Чехрон

## Цель спринта

Собрать базовый контур системы учёта заявок: регистрация заявки,
просмотр списка и личный кабинет студента. По итогам спринта
диспетчер может зарегистрировать заявку, а студент — увидеть её
в своём списке.

## Взято в спринт

| № | История | Поинты |
|---|---------|--------|
| 1 | Регистрация заявки студентом | 5 |
| 2 | Просмотр списка заявок диспетчером | 5 |
| 3 | Личный кабинет студента со статусами | 8 |
| 4 | Настройка авторизации | 3 |

**Итого запланировано:** 21 поинт.
**Velocity команды:** ~14 поинтов за спринт (по симуляции).
**Реалистичный план:** взять 3 истории на 13–16 поинтов.

## Что считаем готовым (DoD)

1. Код написан и прошёл ревью.
2. Тесты на ключевую логику зелёные.
3. Работает в Chrome и Firefox.
4. Документация в `docs/` обновлена.
5. Владелец продукта принял историю.

## Риски спринта

1. Оценка может быть завышена — не хватит времени.
2. Может выясниться, что нужна интеграция с почтой — не входит в спринт.
