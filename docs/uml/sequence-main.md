# Диаграмма последовательности: ключевой сценарий

## Сценарий

«Назначение исполнителя на заявку» — ключевой сценарий,
определяющий основной поток обработки заявки.

Источник: прецедент UC-02 (ПИС-ЛР5).

## Участники

| Участник | Роль |
|----------|------|
| :Диспетчер | Актор — сотрудник деканата |
| :ФормаЗаявки | UI-компонент |
| :СервисЗаявок | Бизнес-логика |
| :БД | Хранилище данных |

## Поток сообщений
      
| # | От кого      | Кому        | Сообщение |
|---|---------|-----|-----------|
| 1 | :Диспетчер | :ФормаЗаявки | открытьЗаявку() |
| 2 | :ФормаЗаявки | :СервисЗаявок | получитьСвободных() |
| 3 | :СервисЗаявок | :БД | запрос свободных исполнителей |
| 4 | :БД | :СервисЗаявок | список (возврат) |
| 5 | :СервисЗаявок | :ФормаЗаявки | список кандидатов |
| 6 | :ФормаЗаявки | :Диспетчер | список |
| 7 | :Диспетчер | :ФормаЗаявки | подтвердить(Иванов) |
| 8 | :ФормаЗаявки | :СервисЗаявок | назначить(Иванов) |
| 9 | :СервисЗаявок | :БД | сохранить() |
| 10 | :БД | :СервисЗаявок | ок |


## Альтернативный поток

**Если свободных исполнителей нет:**

alt Свободных нет:
:СервисЗаявок → :ФормаЗаявки: предложитьОчередь()
:ФормаЗаявки → :Диспетчер: показать предложение
:Диспетчер → :ФормаЗаявки: поставитьВОчередь()
:ФормаЗаявки → :БД: сохранить статус "В очереди"


## Соответствие коду

| Участник диаграммы | Модуль в коде |
|-------------------|---------------|
| :ФормаЗаявки | `app/templates/form.html` |
| :СервисЗаявок | `app/requests.py` |
| :БД | SQLite через `app/db.py` |
