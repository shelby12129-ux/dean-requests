# C4: Диаграмма контейнеров (уровень 2)

## Назначение

Показывает, из каких крупных блоков (контейнеров) состоит система
и как они взаимодействуют.

## Контейнеры

| Контейнер | Технология | Назначение |
|-----------|-----------|-----------|
| Веб-клиент | HTML, CSS, JS | Интерфейс для студентов и сотрудников |
| Веб-сервер | Python + Flask | Обработка HTTP-запросов, бизнес-логика |
| База данных | SQLite | Хранение заявок, справочников, пользователей |
| Email-сервис | SMTP | Отправка уведомлений |

## Взаимодействие контейнеров

1. **Браузер → Веб-сервер**: HTTPS-запросы (форма подачи, список, отчёты).
2. **Веб-сервер → SQLite**: чтение/запись данных.
3. **Веб-сервер → SMTP**: отправка email-уведомлений.

## Обоснование выбора

**Почему монолит, а не микросервисы:**
- Команда из 2 человек — не потянет поддержку нескольких сервисов.
- Нагрузка мала (деканат — 1000–2000 студентов).
- Простота развёртывания.
- Быстрый старт разработки.

**Почему SQLite, а не PostgreSQL:**
- Один сервер, небольшая нагрузка.
- Простота резервного копирования (один файл).
- Достаточно для MVP.

Эти решения зафиксированы в ADR (см. `adr-001`, `adr-002`).
