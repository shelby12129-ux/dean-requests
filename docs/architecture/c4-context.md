# C4: Диаграмма контекста (уровень 1)

## Назначение

Показывает систему в окружении: кто с ней взаимодействует
и какие внешние системы участвуют.

## Система

**Система учёта заявок студентов в деканате** — веб-приложение
для подачи, обработки и отслеживания заявок студентов.

## Акторы

| Актор | Роль | Что делает |
|-------|------|-----------|
| Студент | Пользователь | Подаёт заявки, следит за статусом |
| Сотрудник деканата | Заказчик, пользователь | Обрабатывает заявки, назначает исполнителей |
| Администратор | Пользователь | Управляет справочниками и пользователями |

## Внешние системы

| Система | Назначение | Тип связи |
|---------|-----------|-----------|
| Email-сервис (SMTP) | Отправка уведомлений студентам | SMTP |
| База данных | Хранение заявок и справочников | Локальная |

## Схема (текстовое описание)

Студент] ─── HTTPS ───> [Система учёта заявок] ─── SMTP ───> [Email-сервис]
│
│
▼
[База данных]

[Сотрудник деканата] ─── HTTPS ───> [Система]
[Администратор] ─── HTTPS ───> [Система]


## Что НЕ входит в контекст

- Интеграция с бухгалтерией.
- Мобильное приложение.
- Электронная подпись.
- Внешние системы вуза (1С, СЭД).

Эти системы явно исключены из границ проекта (см. ПИС-ЛР1).
