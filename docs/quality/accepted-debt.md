# Осознанно принятый технический долг

## Что оставляем и почему

### Д-4: SQLite вместо PostgreSQL

**Почему оставляем:** в учебном проекте нагрузка до 2000 студентов.
SQLite достаточно. Миграция — задача на будущее.

### Д-5: Нет фронтенда

**Почему оставляем:** в рамках ПИ проверяется **инженерный процесс**,
а не работающий UI. UI — задача ПИС (1С-конфигурация).

### Нет интеграции с бухгалтерией

**Почему:** исключено из границ проекта (ПП-ЛР1).

### Нет авторизации по JWT

**Почему:** учебная авторизация на словаре достаточна.
JWT — задача production-версии.

## Критерий «осознанности»

Долг принят осознанно, если:
1. Есть письменное обоснование.
2. Понятны риски.
3. Понятно, когда вернуться (весна, следующий релиз).
