# Система учёта заявок студентов в деканате

Проект команды 3 курса «Прикладная информатика» по дисциплинам
«Программная инженерия», «Проектирование ИС» и «Проектный практикум».

## Проблема и пользователи

Заявки студентов в деканате обрабатываются вручную: почта и бумажный журнал.
Заявки теряются, сроки срываются, студент не видит статус.
Пользователи: студенты, сотрудники деканата, администратор.

## Ключевые функции первого релиза

- подача заявки студентом через веб-интерфейс;
- назначение исполнителя из числа сотрудников;
- отслеживание статуса заявки студентом;
- формирование отчётов для деканата.

## Установка и запуск

### Локально

1. Установить зависимости:

pip install -r requirements.txt

2. Запустить тесты:

pytest -v

3. Проверить линтером:

ruff check app/

### Через Docker

1. Собрать образ:

docker build -t dean-requests:v1.0.0 .

2. Запустить:

docker run --rm dean-requests:v1.0.0

## CI/CD

Проект использует GitHub Actions:

- `ci.yml` — линтер + тесты на каждый коммит.
- `release.yml` — тесты + сборка Docker при теге `v*`.
